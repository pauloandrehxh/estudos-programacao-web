# 🌐 Programação WEB

Este repositório contém todos os meus códigos, receitas e anotações referentes à disciplina de **Programação WEB**.

## 📂 Como o repositório está organizado?
- **/receitas**: Exercícios práticos guiados (como as receitas de HTML, CSS e JS).
- **/estudos**: Códigos e anotações gerais sobre os tópicos da disciplina.

---

## 📚 Conteúdos da Disciplina

Aqui estão os principais tópicos abordados ao longo do curso:

### 🟠 Fundamentos (HTML, CSS e JS)
- Introdução aos Sistemas Web
- HTML básico, marcas e princípios gerais
- Variáveis, objetos JavaScript e notação JSON
- Funções, iterações e funções de coleções (`join`, `map`)
- Arrow functions e callback functions
- Async, await, fetch e consumo de APIs externas
- Formulários e requisições via JavaScript
- Objetos como mapas/dicionários
- Promises e processamento assíncrono
- Operador Spread (3 dots) e Classes

### 🔵 React
- Introdução ao React e ao JSX
- Componentes funcionais e de Classes
- Propriedades (Props) e Desestruturação
- Gerência de estados básica com Hooks

### ⬛ Next.js
- Introdução ao NextJS (Páginas e componentes)
- Interação com sistemas externos (Front-end e Back-end)
- Hooks e formulários para pesquisas personalizadas
- Layouts, páginas de loading e UI streaming
- Rotas dinâmicas e geração estática de conteúdo
- Implementação de API
- Server actions
